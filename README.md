# Amazon Product Rating Prediction and Recommendation System
Product rating prediction and recommendation using Python and Linear Regression


## Project Overview
This project uses Machine Learning to predict product ratings and rank products based on their predicted ratings.

## Technologies Used
- Python
- Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Linear Regression

## Workflow
1. Load and explore the product dataset.
2. Select product features such as price, discount, and review count.
3. Split the dataset into training and testing sets.
4. Train a Linear Regression model.
5. Evaluate predictions using MAE and R².
6. Rank products based on predicted ratings.

## Dataset
The included sample dataset contains product names, categories, prices, discounts, review counts, and ratings. It is synthetically generated for educational purposes.

## How to Run
1. Install the required libraries.
2. Download the notebook and CSV dataset.
3. Keep both files in the same folder.
4. Open the notebook in Jupyter and run the cells in order.

## Outcome
Built a basic machine learning workflow for rating prediction and product ranking, including model evaluation and data visualization.
